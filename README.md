# x-distillation

Distillation notes for X (Twitter) hot posts, for account @O26Tx.
Phase 1 only: distill + like / save / repost. No replies, no original posts yet.

## Nearest goal

Reach X Original Content Rewards minimum as fast as possible:
500 verified followers + 500,000 verified Home Timeline impressions in 90 days
(replies excluded). Traffic and interaction over professionalism.

## What a distillation is

Learning the writing, not copying the post. Each note keeps:
1. Source snapshot — who, when, what the post is, link only.
2. Reusable pattern — hook / structure / length / tone / media form / CTA.
3. Usable judgement — what to reuse, what to avoid, OCR risk.

Original text is kept only as a link plus a short quotation for comparison.
No full reposts, no downloaded images or videos in this repo.
Images / video live in Google Drive, linked from the note if needed.

## Daily pace

Deep distillation: 6–10 posts/day, rotating across the 10 fields.
A field is not covered every day. Rotation and counts are logged in `index.md`.

## File naming

`YYYY-MM-DD-<post-id-or-short-slug>.md` inside the field folder.
One file per distilled post. `index.md` in each field folder lists its notes.

## Rules

- Public repo. Never put logins, cookies, API keys, or private information here.
- Never present a distilled pattern as a promise of reach or revenue.
- If a source post is later found to be false, AI-faked, or Community Noted, mark the note `DO NOT USE` — do not delete the record.
